# Retro Game Engine

## Emulator Cores
- NES (Nestopia)
- GBA (mGBA)
- GB/GBC (Gambatte)
- SNES (Snes9x)
- Genesis (Genesis Plus GX)
- PlayStation (PCSX ReARMed)
